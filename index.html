Welcome to Roblox Intel

An all-in-one dashboard for exploring Roblox players, places, groups and their networks. Everything runs in your browser.

01 / LOOKUP
Player Dossier
Look up any user by ID or username — friends, groups, badges, limiteds, real-time activity, social links.
02 / PLACES
Charts & Places
Browse Roblox charts, search games by name, filter by genre, online count, creation date. Live online history graphs. Public servers with join.
03 / GRAPH
Friend Network
Visualise any user's friends as an interactive tree. Find how two users are connected. Zoom and pan supported.
04 / NOTIFICATIONS
Automation
Time reminders, presence alerts, and auto-join games at a scheduled time. Runs while the page is open.
05 / FAVORITES
Favorites
Save players and places, track activity in the background while the page is open.
